# Security

Use the latest release and supported versions of WordPress, PHP, Redis or Memcached, and the PHP cache extension. Configure only trusted cache servers on private networks. Protect the options database, installed drop-in, and backups containing credentials or cached personal data.

Do not publish credentials, personal data, exploit payloads, or sensitive diagnostics in public issues. Use GitHub private vulnerability reporting through this repository's Security tab when available. If private reporting is unavailable, ask the maintainer in a public issue for a private contact channel without including vulnerability details.

The repository's ordinary bug tracker is suitable for non-sensitive problems. This policy does not promise a fixed response time.
